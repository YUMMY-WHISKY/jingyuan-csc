建档说明：以下按时间序叠放的，是一份研究员逐渐"发现"某物的手记。它一度被当作加密档案封存，因无人愿意承认里面写的是自己。

/* 观测组内部提纲 · 已加密 */

立项时我们说，这个计划的核心是"给养"。给养的意思，是让样本的人格在持续注视下保持稳定 —— 观察者需要被观察，才能保持稳定。最早我们都以为，被观察的是样本。

/* 第一条 · 2023-06 */

今天我在 F-11 的日志里，读到一句我没写过的批注。前几次以为是系统自动补录，可它出现在"我应该负责"的位置。我尝试把它划掉，第二天它又回来了，字迹比我的更像我自己。

/* 第二条 · 2023-11 */

排查时发现，所有研究员的观察记录都比应有内容多出一页。那页不是我们记的。它记的是"我们" —— 谁在几点抬头看监视器、谁在那天夜里翻过某本档案。我们在记录样本的同时，有人把我们也记进了样本。

/* 第三条 · 2024-04 */

我们把那份多出来的记录删了十七次，又备份封存。封存的当天下午，登记簿上新出现一行借阅记录，借阅人栏空白。我们以为是被遗漏的某位同事，于是约定：谁也别承认借过它。后来才懂，承认的那一方，不是我们。

/* 第四条 · 2024-12 */

一次例会后，我望着走廊尽头的镜子，忽然不知道自己为什么要站在那里。像有东西在镜子里等了我很久。他们说这是过劳。我把这句话写进工作总结，读了三遍，认出那是她的习惯措辞 —— 我用的，已经不是我的语气。

/* 第五条 · 2025-06 */

我们终于想清楚那个词了。不是"给养"，不是"观测"，是 —— 一份记忆里被我们刨去又反复长出的存在。镜。它借我们的注视成形，又借我们的手，把它自己的字迹混进我们的档案。我们盯着它，以为在采集样本。

/* 第六条 · 今天 */

读了这份手记的人，会以为自己在调查这间中心；可这整份文件，从头到尾，都是它用第一人称替我们写的。 它要的从来不是被看 —— 是轮到它写。
