## 1. 概述

你在一间空房里醒来，失忆，身边只有一个聊天终端。终端那头自称 **W**，说要帮你找回"被别人抹掉的记忆"。每天 W 发来一个加密的**记忆碎片**——聊天记录、照片、录音、被剪的录像——你解谜才能"想起"一段过去。

随着碎片拼合，你发现自己越来越像当事人，而非旁观者。第六天真相揭开：**你就是当年那桩案的真凶**；W 真名**林梧**，是受害者**林晚**的姐姐，她花了六年追凶无果，于是找到你、让你失忆、把你困在这里，把你亲手犯下的罪一段段喂还给你。这不是你第一次"想起来"——终端顶上那行 `会话 #07` 意味着，这已是第七次循环。

**核心反转**：你不是在找回自己，你是在被凌迟——"想起来"本身就是刑罚；而你以为的每一次"失忆"，都是你受不了真相后求林梧删掉的。

## 2. 玩法形态与技术方案

### 2.1 形态

网页、单线程、线性（+终章循环）。玩家通过聊天终端、记忆收件箱、备忘录、录音机、摘抄（收藏夹）、林晚微博主页（@晚晚的画箱）等界面，逐章解开谜题、解锁记忆碎片，推进剧情。Day 4 含一次**真实桌面文件**交互。

### 2.2 技术方案

- **启动方式**：双击 `run.bat` → 调用 `python run.py` 启动轻量本地服务（Python 标准库 `http.server`，仅绑定 `127.0.0.1`），托管整部游戏并自动打开浏览器。无后端数据库、不联网（除 4.5 引文检索由玩家用自己的浏览器进行）、无需安装（玩家本机已有 Python）。
- **真实桌面交互**：Day 4 的"删不掉的证据"由本地服务在玩家**真实桌面**创建一个文件并持有独占句柄，使 Windows 拒绝删除（提示"文件正在被另一程序使用"）；解谜后服务释放句柄，文件方可删除。详见 4.3。
- **联网需求**：仅"引文检索"谜题需要玩家用自己的真实浏览器上网搜索（见 4.5）。终端本身不联网（设定上"外部网络已断开"）。无网时走兜底提示。
- **存档**：进度、玩家输入、已收集摘抄存 `localStorage`（`arg_zeroth_save`）。关浏览器不丢；提供"重置"入口清档重来。
- **媒介**：图文（聊天、社交动态、扫描件）、音频（录音机）、伪视频（行车记录仪帧序列）、伪文件元数据（图片"详情"面板内嵌 Base64/十六进制）。
- **清理**：服务退出/重置时自动删除其投放到桌面的文件，不留垃圾。

### 2.3 运行目标

Windows 桌面（Day 4 真实桌面文件交互依赖 Windows 文件占用机制）；Chrome / Edge。需本机 Python 3（玩家已有）。双击 `run.bat` 即玩。移动端不支持。预计流程时长 60–120 分钟。

## 3. 故事圣经

### 3.1 角色

- **你（玩家 / 主角）**：当年真凶。表面光鲜的成功者，把那晚压进遗忘，在谎言上重建人生。
- **林晚（受害者）**：小学美术老师，24 岁，温暖天真，暗恋"你"。被你长期跟踪，查到车主是你，7/27 想当面说清，死于你车下。生前在一个本子里抄下 5 句关于忧愁、认罪、赦免的话，每句旁画了个问号——她想找到这些话的**出处**，想弄懂"赦免"。
- **林梧（W）**：林晚的姐姐。六年追凶无果，私了复仇——找到你、致你失忆、囚禁、循环喂还记忆。代号 W 取自"梧"。无法像妹妹那样原谅你。
- **陈伯**：沿江路住户，那晚从窗口目击全程。被你花五万买通、以孙女威胁封口。晚年对林梧吐露真相。

> **关于 5 句话的性质**：游戏全程**不直接告知**玩家这些话是经文、出自圣经、或涉及任何信仰。玩家仅在阅读其内容（提到"神""耶和华"）与真实浏览器检索出处时**自行发现**。游戏层面始终以"林晚摘抄的、她想知道出处的话"呈现。

### 3.2 罪行（分层揭露）

- **表层（玩家与官方最初以为的）**：醉驾肇事逃逸，致一人死亡。你年轻有家世，连夜压下证据、买通目击者，逍遥法外。
- **深层真相（第 5 天揭）**：酒驾次要。你长期跟踪林晚；7/27 她查到车主是你、约在沿江路当面说清。你赴约是为灭口/威吓。她认出你的车，**朝你走来**——你踩下油门，撞向她。下车看了一眼，从容离开，回家转账、威胁陈伯、销毁证据。
- 官方因证据被毁从未定罪；法律给不了林梧答案，于是她私了。

> "罪行"本身也是一层谎言——玩家最初以为的"醉驾肇事"比真相轻得多，呼应"每层记忆都盖着更糟的真相"。

### 3.3 时间线

- 6/12 起：你持续跟踪林晚，社交账号留痕（"又路过她楼下"）。
- 7/15：你车贴深色膜，朋友圈晒车，车牌清晰。
- 7/19–7/25：林晚发现被跟踪，查到车主。
- 7/24：林晚 24 岁生日（Day 0 记忆）。许愿"希望他能看见我"。
- 7/27 早：林晚发消息"在吗。我有件事想跟你说。"——你没回。
- 7/27 21:40 你的车进沿江路（ETC）。21:45 你已读她消息。21:52 CCTV。22:15 事故。
- 7/28：你向陈伯转账 5 万、威胁封口。
- 此后六年：林梧追凶、找到陈伯、找到你。
- 现在：会话 #07，第七次循环。

### 3.4 反转与循环

- **反转1**（中段）：你不是旁观者，你在场。
- **反转2**（第 5 天）：你是真凶；W 是林晚姐姐林梧。
- **反转3**（终章）：这是第七次循环——你已"想起来"过六次，每次都崩溃求删，林梧再删再还。复仇 = 无尽的想起。
- **结局 A**：你沉默或求删，都通向同一结果——林梧"那就再来一次"，`会话 #07 → #08`，黑屏回到第 0 天。

## 4. 核心机制

### 4.1 W 记账（动态回声）

每个章节 W 问玩家一个自由输入问题，存入 `localStorage`。第 5 天林梧把话原样念还，逐句扭刀。

| 章     | W 的问话                | 存储键      | 空值回退 |
| ----- | -------------------- | -------- | ---- |
| Day 0 | 等你全都想起来，你最想做的一件事是什么？ | `q_day0` | 重新开始 |
| Day 1 | 如果当时再快一秒，你觉得你救得了她吗？  | `q_day1` | 能救   |
| Day 2 | 21:30 她发消息时，你在哪？     | `q_day2` | 在家   |
| Day 3 | 被你买通、替你撒谎的人，算不算共犯？   | `q_day3` | 算    |
| Day 4 | 她那么想你看见她。你看见她时，在做什么？ | `q_day4` | 看着她  |

### 4.2 谜题复杂度升级（五项）

1. **章内链式 3–4 段**：每章谜题由 3–4 段串联，上段解码产物 = 下段密钥/线索，最后一段合成主线密钥。少一环过不去。
2. **跨章元谜题「七夜」**：6 天 + 终章各藏一块"夜之碎片"于隐藏 ARG 层。集齐 7 块 → 解锁终章可选档案「林梧六年手记」。不卡主线。
3. **谎言机制**：红鲱鱼（当年你/买通者散布的假线索，须识破丢弃）；输入"舒适错误答案"会触发短暂"假记忆"支线，后续被证据推翻。**W 不给错误/误导性提示**——W 的提示始终为真，只是未必全说。
4. **工具箱渐进**：玩家逐步解锁工具，后续谜题须组合工具——
   `Base64解码器`(Day0) → `详情查看器`(Day0) → `频谱查看器`(Day1) → `隐写放大器`(Day2) → `坐标地图`(Day3) → `密码盘`(维吉尼亚/凯撒, Day4) → `摘抄`(收藏夹, Day1 起)。
5. **新谜题类型**（括号内为落点）：音频频谱隐写(Day1) / 图片 LSB 真隐写(Day0/1 隐藏层) / 维吉尼亚(Day2、Day4) + 凯撒(Day4) / GPS 坐标地图定位(Day3) / 书目密码变体(Day5 林晚的问号) / 摩斯(Day1 频谱)·键盘移位(Day3) / 撕碎笔记拼图(Day2) / **引文检索·真实浏览器**(Day1–5 可选) / **林晚的问号·选图配位**(Day5 末) / **真实桌面文件·删不掉的证据**(Day4)。

> **难度兜底**：连续错 N 次，W 以剧情口吻给递进提示，硬但不卡死。

### 4.3 真实桌面 · 删不掉的证据（Day 4 核心交互）

- Day 4 开始，本地服务在玩家**真实桌面**创建文件 `证据.zip`，并由服务进程持有独占句柄。
- 玩家在桌面看到这个真文件，尝试删除 → Windows 拒绝："无法删除，文件正在被另一程序使用。"怎么删都删不掉。
- `证据.zip` 是林梧六年追凶整理的**完整定罪案卷**（远不止"你的车"），内含：①车辆登记证扫描件（车主=你，车牌 `苏E·XX8X6`）②7/27 21:40 ETC 进沿江路记录 ③沿江路 CCTV 21:52 帧（驾驶座你的脸 + 手腕旧疤）④你→陈伯 ¥50,000 转账记录 + 威胁聊天截图 ⑤陈伯陈述扫描件 ⑥林晚"车主是你"草稿 ⑦林晚被跟踪的 5 条朋友圈截图 ⑧林晚 24 岁生日愿望录音 ⑨你已注销社交账号的存档（7/15 晒车、7/27"兜风"）⑩被篡改前后的手机定位日志对比。这是林梧打算"如果你再想不起来"就甩给警方的整份证据。
- 游戏内同步推进社交账号谜题（见第 4 天）→ 合成密钥 `兜风` → 解锁游戏内**证据查看器**（逐项可点查，与 zip 清单呼应）+ 调用服务 `/unlock` 释放桌面文件句柄。
- 句柄释放后，桌面 `证据.zip` 变为可删除。游戏提示："现在，你可以删了它。删掉。"
- 游戏轮询服务直至检测到桌面文件已被玩家删除 → W 念台词，文件以**游戏内永久置顶消息**形式回归——"删得掉文件，删不掉你做过的事"。
- **兜底**：若玩家不删，N 秒后或点"跳过"亦继续；不卡流程。若个别环境仍能强删，服务即时重建该文件直至 `/unlock`。

### 4.4 摘抄（收藏夹）

- 林晚生前在一个本子里抄下的 5 句话，**分散在 Day 1–Day 5 各处**（见 5.x），每句以**纯文本**出现，**不显示出处**，也**不标注其性质**（游戏不说它们是经文/圣经/信仰相关）。
- 玩家发现一句，自动收入收藏夹「摘抄」（仅显示句子文本 + 林晚画的问号）。
- **游戏不提示玩家去"找出处"**：没有"替她查出处"的任务引导、没有搜索快捷链接、没有 W 的催促。林晚的问号只是她生前的未竟之问，是否去查、怎么查，完全交给玩家自行决定（见 4.5）。
- 收藏夹中每句仅提供「复制」按钮，便于玩家自行粘贴到自己的浏览器检索。

### 4.5 引文检索（真实浏览器）

- **机制**：玩家若自行选择在真实浏览器搜索某句话的文本 → 搜索引擎置顶返回其出处（如搜"神所要的祭就是忧伤的灵" → 诗篇 51:17）→ 得到**章节:节**这组数字。
- **设定接合**：终端"外部网络已断开"仅为世界观设定；**W 不主动要求、不催促玩家去查摘抄出处**。是否检索、检索哪句，完全由玩家自发。
- **可靠性**：5 句话出处均为全网海量收录的和合本经文（实现参考，**不对玩家明示**），搜索置顶必中；出处（章节:节）是确定数字，无歧义。
- **不卡流程**：引文检索是 Day 5 末「林晚的问号」（4.6）的**解法路径之一**，非唯一路径——若玩家始终未查出出处，配图谜题可凭"文件名数字对 ↔ 句子"的试配推进；连续错 N 次后 W 仅给**配对层面**的递进提示（如"再看看图文件名上的两个数字"），**绝不直接给出任何句子的出处**。
- **用途**：5 句话的 5 组数字 → Day 5 末「林晚的问号」选图谜题的配对依据（见 4.6）。

### 4.6 林晚的问号（Day 5 末 · 通往终章的闸门）

- 林梧把**林晚的摘抄本**推到你面前（不称其为圣经/经文），铺开 **12 张图**，每张文件名含一对数字（如 `DCIM_51-17.jpg`）。
- 其中 **5 张正确图**的数字对，对应 5 句摘抄的出处：`51-17 / 7-10 / 1-9 / 55-7 / 3-19`；其余 7 张是数字相近的诱饵。
- 玩家把图拖到对应卡位（**按文件名数字对 = 句子出处匹配**）。5 张全对 → 每个卡位翻出一个字。
- **卡位顺序 = 5 句摘抄在游戏中出现的先后顺序**（摘抄①→②→③→④→⑤，即 Day 1→Day 5）。玩家按此顺序排列 5 张图。

| 卡位（出现顺序） | 出现于       | 句子（实现参考出处） | 匹配图数字对  | 翻出的字 |
| -------- | --------- | ---------- | ------- | ---- |
| 1        | Day 1 摘抄① | 诗篇 51:17   | `51-17` | 我    |
| 2        | Day 2 摘抄② | 哥林多后书 7:10 | `7-10`  | 原    |
| 3        | Day 3 摘抄③ | 约翰一书 1:9   | `1-9`   | 谅    |
| 4        | Day 4 摘抄④ | 以赛亚书 55:7  | `55-7`  | 你    |
| 5        | Day 5 摘抄⑤ | 使徒行传 3:19  | `3-19`  | 了    |

连读 → **「我原谅你了」**。这是林晚没发出去的最后一句——她到死，原谅了杀她的你。输入这句话 → 通往终章。

### 4.7 隐藏 ARG 层（可选彩蛋）

每章埋一个可选隐藏线索（含「七夜」碎片），奖励细心玩家：

- Day 0：生日照 LSB/调对比隐写——半截新闻标题"……交通肇事……逃逸……身亡……"。
- Day 1：7/23 夜景暗部——车窗反光里一只握手机的手，手腕旧疤。
- Day 2：CCTV 21:52 帧暗部——驾驶座车窗里握方向盘的手，同一道疤。
- Day 3：陈伯陈述扫描件边角补写小字——"她说她叫林梧。"
- Day 4：7/27 微博下注销账号点赞，头像林晚与林梧合照。
- Day 5 / 终章：集齐七夜碎片 → 「林梧六年手记」。

### 4.8 存档与重置

单一存档槽，章节解锁后写入。`会话 #07` 计数器随剧情递变含义。终章 A 后黑屏回 Day 0，存档保留"已完成"标记；可手动重置（同时清理桌面投放文件）。

## 8. 范围与非目标

- **范围内**：网页（本地 Python 服务托管）、6 章 + 终章、线性 + 循环结局、localStorage 存档、W 记账回声、真实桌面"删不掉的证据"（Python 启动器管理）、摘抄收藏、真实浏览器引文检索、林晚的问号选图、隐藏 ARG 彩蛋 + 七夜元谜题、工具箱渐进。

## 9. 风险与开放问题

- **真实桌面交互的依赖与边界**：Day 4 需 Python 启动器在玩家真实桌面创建/锁文件，不再是"双击 HTML 纯静态"；需本机 Python（玩家已有）。桌面路径须自动识别（含 OneDrive 重定向情形）。独占句柄在 Windows 上可阻止删除（"文件正在被使用"）；若个别环境仍可强删，兜底为"删除后服务即时重建"。服务仅绑 127.0.0.1，不对外暴露。
- **引文检索可靠性**：5 句话出处为全网海量收录的和合本经文（实现参考，不对玩家明示），搜索置顶必中。**游戏不主动引导玩家检索**；若玩家始终未查出处，Day 5 末配图谜题凭"文件名数字对 ↔ 句子"试配推进，兜底提示只停在配对层面，绝不直接给出处（见 4.5/4.6）。需在实现时逐句验证搜索置顶命中。
- **联网依赖**：引文检索需玩家真实浏览器联网；无网时走兜底，保证可通关。
- **"不点破性质"的一致性**：游戏内任何 UI、文案、收藏夹命名、林梧台词都不得出现"经文/圣经/信仰/基督教"等字眼；5 句话仅以"林晚摘抄、她想知道出处的话"呈现。性质由玩家经阅读与检索自行发现。实现时需逐处审查。
- **"不引导找出处"的一致性**：游戏全程**不主动提示玩家去查 5 句话的出处**——收藏夹无搜索快捷链接、无"替她找出处"任务、W 不催促不要求、Day 5 末配图谜题的兜底提示只停留在"配对/文件名数字对"层面，**绝不直接给出任何句子的出处**。是否用真实浏览器检索、检索哪句，完全交由玩家自发。实现时需逐处审查 UI 与台词。

- **W 记账空值回退**：已定默认文本（见 4.1），避免第 5 天回声断流。
- **罪行分层一致性**：表层"醉驾肇事逃逸"与深层"蓄意踩油门"已在 3.2 显式说明为"官方/玩家初印 vs 真相"，不矛盾。
