# 《第零个》— ARG 设计文档

> 主题：记忆 / 身份错乱（⑤单飞）  
> 形态：网页 + 多媒介伪线索（B）  
> 结局：A · 循环硬结局  
> 创建日期：2026-08-07

---

## 1. 概述

你在一间空房里醒来，失忆，身边只有一个聊天终端。终端那头自称 **W**，说要帮你找回"被别人抹掉的记忆"。每天 W 发来一个加密的**记忆碎片**——聊天记录、照片、录音、被剪的录像——你解谜才能"想起"一段过去。

随着碎片拼合，你发现自己越来越像当事人，而非旁观者。第六天真相揭开：**你就是当年那桩案的真凶**；W 真名**林梧**，是受害者**林晚**的姐姐，她花了六年追凶无果，于是找到你、让你失忆、把你困在这里，把你亲手犯下的罪一段段喂还给你。这不是你第一次"想起来"——终端顶上那行 `会话 #07` 意味着，这已是第七次循环。

**核心反转**：你不是在找回自己，你是在被凌迟——"想起来"本身就是刑罚；而你以为的每一次"失忆"，都是你受不了真相后求林梧删掉的。

---

## 2. 玩法形态与技术方案

### 2.1 形态
纯网页、单线程、线性（+终章循环）。玩家通过聊天终端、记忆收件箱、备忘录、录音机、仿真桌面等界面，逐章解开谜题、解锁记忆碎片，推进剧情。

### 2.2 技术方案
- **纯静态站点**（HTML / CSS / 原生 JS），双击 `index.html` 即玩。无后端、无数据库、无需安装、不联网。
- **存档**：进度与玩家输入存 `localStorage`（`arg_zeroth_save`）。关浏览器不丢；提供"重置"入口清档重来。
- **第四墙交互**："和玩家电脑交互"用**仿真桌面窗口**实现（在终端里弹出一个仿"此电脑/桌面"，文件可右键、可拖入回收站、可清空），体感与真实删文件一致，但仅在网页内运行，不触碰真实文件系统。
- **媒介**：图文（聊天记录、社交动态、扫描件）、音频（录音机）、伪视频（行车记录仪帧序列）、伪文件元数据（图片"详情"面板内嵌 Base64/十六进制）。
- **谜题实现**：均为前端 JS 校验——排序、密码输入、Base64/十六进制解码、填空还原、隐写（模拟，调对比度/查看"详情"即现）。

### 2.3 运行目标
桌面浏览器（Chrome / Edge）。移动端不保证。预计流程时长 45–90 分钟。

## 3. 故事圣经

### 3.1 角色
- **你（玩家 / 主角）**：当年真凶。表面是光鲜的成功者，把那晚压进遗忘，在谎言上重建人生。
- **林晚（受害者）**：小学美术老师，24 岁，性格温暖、天真。暗恋"你"。被你长期跟踪，查到车主是你，7/27 想当面说清，死于你车下。
- **林梧（W）**：林晚的姐姐。六年追凶无果，私了复仇——找到你、致你失忆、囚禁、循环喂还记忆。代号 W 取自"梧"。
- **陈伯**：沿江路住户，那晚从窗口目击全程。被你花五万买通、以孙女威胁封口。晚年良心不安，对林梧吐露真相。

### 3.2 罪行（分层揭露）
- **表层（玩家与官方最初以为的）**：醉驾肇事逃逸，致一人死亡。你年轻有家世，连夜压下证据、买通目击者，逍遥法外。
- **深层真相（第 5 天揭）**：酒驾只是次要。你长期跟踪林晚；7/27 她查到车主是你、约在沿江路当面说清。你赴约是为灭口/威吓。她认出你的车，**朝你走来**——你踩下油门，撞向她。下车看了一眼，从容离开，回家转账、威胁陈伯、销毁证据。
- 官方因证据被毁从未定罪；法律给不了林梧答案，于是她私了。

> 设计意图："罪行"本身也是一层谎言——玩家最初以为的"醉驾肇事"比真相轻得多，呼应"每层记忆都盖着更糟的真相"。

### 3.3 时间线
- 6/12 起：你持续跟踪林晚，社交账号留痕（"又路过她楼下"）。
- 7/15：你车贴深色膜，朋友圈晒车，车牌清晰。
- 7/19–7/25：林晚发现被跟踪，查到车主。
- 7/24：林晚 24 岁生日（Day 0 记忆）。她许愿"希望他能看见我"。
- 7/27 早上：林晚发消息"在吗。我有件事想跟你说。"——你没回。
- 7/27 21:40：你的车进沿江路（ETC）。21:45 你已读她消息。21:52 CCTV 拍到你的车。22:15 事故。
- 7/28：你向陈伯转账 5 万、威胁封口。
- 此后六年：林梧追凶、找到陈伯、找到你。
- 现在：会话 #07，第七次循环。

### 3.4 反转与循环
- **反转1**（中段）：你不是旁观者，你在场。
- **反转2**（第 5 天）：你是真凶；W 是林晚姐姐林梧。
- **反转3**（终章）：这是第七次循环——你已"想起来"过六次，每次都崩溃求删，林梧就再删再还。复仇 = 无尽的想起。
- **结局 A**：你沉默或求删，都通向同一结果——林梧"那就再来一次"，`会话 #07 → #08`，黑屏回到第 0 天。

## 4. 核心机制

### 4.1 W 记账（动态回声）
每个章节 W 会问玩家一个自由输入的问题，玩家的话被存入 `localStorage`。第 5 天，林梧把这些话**原样念还**，逐句扭成刀。

| 章 | W 的问话 | 存储键 |
|---|---|---|
| Day 0 | 等你全都想起来，你最想做的一件事是什么？ | `q_day0` |
| Day 1 | 如果当时再快一秒，你觉得你救得了她吗？ | `q_day1` |
| Day 2 | 21:30 她发消息时，你在哪？ | `q_day2` |
| Day 3 | 被你买通、替你撒谎的人，算不算共犯？ | `q_day3` |
| Day 4 | 她那么想你看见她。你看见她时，在做什么？ | `q_day4` |

- 若玩家未输入（空值），使用默认回退文本，保证第 5 天回声不断流：
  - `q_day0`→"重新开始"、`q_day1`→"能救"、`q_day2`→"在家"、`q_day3`→"算"、`q_day4`→"看着她"。

### 4.2 谜题类型目录
1. **排序**：朋友圈/时间线按时间戳正序排列。
2. **密码输入**：数字、词组（密钥来自线索拼合）。
3. **解码**：Base64、十六进制（藏在伪"图片详情"或文本中）。
4. **填空还原**：涂黑聊天/陈述，依上下文补全。
5. **隐写（模拟）**：调高对比度 / 查看伪元数据，浮现隐藏文字或图像。
6. **序列招供**：拖拽排列事件真序（Day 5 招供谜题）。

每章 2–3 个互相关联的谜题，循环变体与叠加，不做显式教学。

### 4.3 仿真桌面 · 删不掉的证据（Day 4 核心交互）
- 文件 `证据_你的车.zip` 出现在仿真桌面。
- 玩家可右键删除 / 拖入回收站 / 清空回收站；每次"删"后文件回到原处，弹窗嘲讽（"你上次也清空过。管用吗？"）。
- 解开加密（密钥由社交账号线索合成）后，文件解锁、内容呈现，状态转为"可删除"。
- 玩家删除后，W 念出台词，文件以**永久置顶消息**形式回归——"删得掉文件，删不掉你做过的事"。

### 4.4 隐藏 ARG 层（可选彩蛋）
每章埋一个可选隐藏线索，奖励细心玩家，提前埋设真相：
- Day 0：生日照片 LSB/调对比隐写——半截新闻标题"……交通肇事……逃逸……身亡……"。
- Day 1：7/23 夜景暗部——车窗反光里一只握手机的手，手腕旧疤/ distinctive 表。
- Day 2：CCTV 21:52 帧暗部——驾驶座车窗里握方向盘的手，同一道疤。
- Day 3：陈伯陈述扫描件边角补写小字——"她说她叫林梧。"
- Day 4：7/27 微博下注销账号点赞，头像是林晚与林梧合照。

### 4.5 存档与重置
- 单一存档槽，章节解锁后写入。`会话 #07` 计数器随剧情推进含义递变。
- 终章 A 结局后，黑屏回到 Day 0，存档保留"已完成"标记；可手动重置。

## 5. 章节设计

### 第 0 天 · 醒来（v2）
- **开场**：冷绿自检日志逐行打出（`[ OK ]会话 #07` / `[ !! ]外部网络：已断开` / `[ ?? ]受试者编号：▓▓▓▓`）。四个可点界面：聊天窗、记忆收件箱、备忘录、录音机；灰掉摄像头图标显示空房间（墙上日历停在 7 月 27 日，墨绿色；门无把手）。
- **W 登场**：不解释规则。问 `q_day0`，存话，发来 `memory_00.enc`。
- **谜题**：备忘录半涂黑便签（"密钥是她笑起来那年的数字"）+ 蛋糕照"林晚 24"+ 详情栏 Base64（解码"名字。岁数。一并交还。"）→ 输入 `林晚24` 解锁。
- **记忆**：生日夜聊天（"那你永远 24 / 说定了"）+ 旁白 + 一条 3 天后未读消息（"在吗。我有件事想跟你说。"，你没回）。
- **埋点**：林晚=受害者；"永远24"（死于24岁）；"跟你有关的愿望"（Day 4）；"3天后没回的消息"（Day 2）；日历 7/27（案发夜）；会话 #07（第七次循环）。
- **隐藏层**：蛋糕照隐写半截肇事新闻标题。
- **W 收尾**："你那时候，还配得上她那样的笑。"（二周目=讽刺）

### 第 1 天 · 那个人
- **W**：引出林晚其人 + 你"在场"的样子；回声 `q_day0`。
- **谜题 A（主线密钥）**：5 条朋友圈截图按时间戳正序排列（7/19–7/27）→ 分钟数拼出 `0727` → 解锁 `memory_01`。内容连读：她最后一周被一辆深色轿车跟踪，7/27"今晚了结"。
- **谜题 B（支线，回收 Day 0）**：林晚加密备忘录，密钥 `林晚24`（她用自己的名字+岁数当密码）→ 偷拍深色轿车，残牌 `苏E·▓8▓6` + 她心声"我想先告诉你"。
- **记忆**：旁白立人（小学美术老师、攒假期想去山里教画）+ 给闺蜜语音（"明天我找他当面说清"）+ 你的"记忆"（7/27 沿江路，你说你只是路过，捡起她碎屏手机读到没发出的消息）+ W 宽慰"你只是来不及"+ `q_day1`。
- **埋点**：深色轿车/跟踪者（Day 4）；残牌（Day 4）；手机屏裂缝（Day 5 闭合）；隐藏层车窗反光里的手腕疤（Day 5）。

### 第 2 天 · 那一晚
- **W**："记忆会骗人。数据不会。"
- **谜题**：电子证据五件（ETC 记录涂黑时间 / CCTV 21:52 / 你的手机定位 / 聊天已读时间 / 林晚草稿）排成时间线 + 解码 ETC 十六进制得 `21:40`。线显：21:30 她发消息→21:40 你的车进沿江路→21:45 你已读→21:52 CCTV→22:15 事故。输入 `21:40` 解锁。
- **记忆**：旁白（记忆崩裂：你"在家"，车却 21:40 在沿江路）+ 林晚草稿"我查到了那辆车的车主。是……" + `q_day2`。
- **隐藏层**：CCTV 21:52 帧驾驶座车窗里握方向盘的手，同一道疤。
- **裂缝累积**：Day 1 手机屏 + Day 2 你不在家。

### 第 3 天 · 目击者
- **W**："你的记忆，挑着回来。"
- **谜题**：转账记录（你→陈伯 ¥50,000，备注十六进制解码"看见的，就当没看见"）+ 已删聊天填空（你威胁他孙女在哪家幼儿园）+ 陈伯真实陈述加密（密钥 `50000`）。
- **记忆**：陈伯陈述（"车里年轻人，下车看了一眼，开走。那姑娘的姐姐找过我"）+ 旁白（你从容）+ `q_day3`。
- **隐藏层**：陈伯陈述边角补字"她说她叫林梧"。
- **裂缝**：你下车看了一眼、从容离开、买通威胁——"路人"形象站不住。

### 第 4 天 · 销毁（社交账号 + 删不掉的证据）
- **W**："互联网有记忆。我也记得。"
- **社交账号线索**：你已注销但被恢复的旧账号——6/12"又路过她楼下"（跟踪）；7/15 晒车深色膜，车牌 `苏E·XX8X6`（对上残牌）；7/27 20:50"今晚沿江路，兜风散心"（你亲口承认在场）。
- **核心交互**：仿真桌面 `证据_你的车.zip` 删不掉（详见 4.3）。密钥由三条动态合成（`兜风`）→ 解锁。
- **解锁内容**：车辆登记（车主=你，车牌对上）+ 林晚草稿完整版"车主是你"+ 她生日愿望录音"我希望他能看见我"。
- **记忆**：旁白（你跟踪她一个半月；她查到是你；她爱你；你开车撞向她）+ W"她那么想你看见她。你确实看见她了——在你车灯底下"+ `q_day4`。
- **隐藏层**：7/27 微博下注销账号点赞，头像林晚与林梧合照。
- **裂缝近乎合拢**：只差"驾驶座上是不是你本人"。

### 第 5 天 · 你就是那个人
- **W**：语气转冷。"最后一块，只能你自己拼。"
- **谜题（招供序列）**：拖拽排列那晚五事件真序——①她走向你的车 ②你踩下油门 ③你撞了她 ④你下车蹲看 ⑤你开车离开。排对解锁最终影像。
- **最终影像**：驾驶座你的脸（仪表冷光）+ 握方向盘的手腕旧疤（同一只）+ 林晚走进车灯 + 你踩油门。
- **林梧现身**：W→林梧。六年追凶、法律无果、私了复仇；`会话 #07`=第七次循环，你已想起来六次，每次求删，她再删再还。
- **念还你的话**：逐句回声 `q_day0–q_day4`，逐句扭刀（"你说再快一秒能救她——你不是来不及，你是踩了油门"等）。
- **闭合裂缝**：墓碑"卒于 7/27，享年 24"（"永远24"回收）；"她手机碎了，你读不到任何字，那段记忆是你编给自己听的"（Day 1 手机屏闭合）；手腕疤=你（Day 1/2 隐藏层回收）。
- **W 收尾**："这是六次里，你第一次没有求我删掉。……那么，这一次，你想怎么办？"

### 终章 · A 循环硬结局
- 无论沉默 / 求删 / 任何选择，通向同一结果。
- 林梧："好。那就再来一次。"
- 终端 `会话 #07 → 会话 #08`。黑屏。回到第 0 天开场自检日志（`[ OK ] 会话 #08`）。
- **复仇 = 无尽的想起。** 玩家亲手体验"循环"——可主动重置，但剧情上永困。

## 7. 美术 / 音效 / 文案基调

- **视觉**：冷绿终端为主，记忆碎片用偏暖的旧照片色调（反差=记忆的温度 vs 现实的冷）。林晚的素材偏暖黄，你的罪证偏冷青。
- **音效**：终端打字声、低频底噪；录音机播放加老式底噪；终章循环时一句极轻的"你又回来了"。
- **文案**：W 克制、近乎温柔、偶露刀锋；旁白文学性，重意象与留白；林晚口语温暖带羞涩。全程简体中文。

## 8. 范围与非目标

- **范围内**：单机网页、6 章 + 终章、线性 + 循环结局、localStorage 存档、W 记账回声、仿真桌面删不掉交互、隐藏 ARG 彩蛋。
- **非目标**：多人/联机；真实文件系统访问；语音合成（仅文字 + 预录/拟音素材）；分支剧情（除循环外）；移动端适配；多语言。

## 9. 风险与开放问题

- **隐写/伪元数据可发现性**：隐藏层需保证"可被细心玩家发现但不被普通玩家误读为 bug"。实现时给极淡的视觉提示（如轻微噪点/可点的"详情"按钮）。
- **W 记账空值回退**：已定默认文本（见 4.1），避免第 5 天回声断流。
- **罪行分层一致性**：表层"醉驾肇事逃逸"与深层"蓄意踩油门"已在 3.2 显式说明为"官方/玩家初印 vs 真相"，不矛盾。
- **循环结局的挫败感**：A 结局刻意无力；以"可主动重置 + 隐藏层带来二周目新视角"作为情绪出口，避免玩家纯粹负面。
- **音频素材**：录音机/终章需要少量人声。若无人声录制条件，用文字 + 底噪 + 波形动画替代，不影响剧情。
