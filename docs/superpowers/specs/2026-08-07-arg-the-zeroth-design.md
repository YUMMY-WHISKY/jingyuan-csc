# 《第零个》— ARG 设计文档

> 主题：记忆 / 身份错乱（⑤单飞）  
> 形态：网页 + 多媒介伪线索（B）  
> 结局：A · 循环硬结局  
> 创建日期：2026-08-07　最后更新：2026-08-07（v3：摘抄 5 句不点破经文性质）

---

## 1. 概述

你在一间空房里醒来，失忆，身边只有一个聊天终端。终端那头自称 **W**，说要帮你找回"被别人抹掉的记忆"。每天 W 发来一个加密的**记忆碎片**——聊天记录、照片、录音、被剪的录像——你解谜才能"想起"一段过去。

随着碎片拼合，你发现自己越来越像当事人，而非旁观者。第六天真相揭开：**你就是当年那桩案的真凶**；W 真名**林梧**，是受害者**林晚**的姐姐，她花了六年追凶无果，于是找到你、让你失忆、把你困在这里，把你亲手犯下的罪一段段喂还给你。这不是你第一次"想起来"——终端顶上那行 `会话 #07` 意味着，这已是第七次循环。

**核心反转**：你不是在找回自己，你是在被凌迟——"想起来"本身就是刑罚；而你以为的每一次"失忆"，都是你受不了真相后求林梧删掉的。

## 2. 玩法形态与技术方案

### 2.1 形态
纯网页、单线程、线性（+终章循环）。玩家通过聊天终端、记忆收件箱、备忘录、录音机、摘抄（收藏夹）、仿真桌面等界面，逐章解开谜题、解锁记忆碎片，推进剧情。

### 2.2 技术方案
- **纯静态站点**（HTML / CSS / 原生 JS），双击 `index.html` 即玩。无后端、无数据库、无需安装。
- **联网需求**：仅"引文检索"谜题需要玩家用**自己的真实浏览器**上网搜索（见 4.5）。终端本身不联网（设定上"外部网络已断开"）。无网时走兜底提示。
- **存档**：进度、玩家输入、已收集摘抄存 `localStorage`（`arg_zeroth_save`）。关浏览器不丢；提供"重置"入口清档重来。
- **第四墙交互**："和玩家电脑交互"用**仿真桌面窗口**实现（仿"此电脑/桌面"，文件可右键、可拖入回收站、可清空），仅在网页内运行，不触碰真实文件系统。
- **媒介**：图文（聊天、社交动态、扫描件）、音频（录音机）、伪视频（行车记录仪帧序列）、伪文件元数据（图片"详情"面板内嵌 Base64/十六进制）。

### 2.3 运行目标
桌面浏览器（Chrome / Edge）。移动端不保证。预计流程时长 60–120 分钟。

## 3. 故事圣经

### 3.1 角色
- **你（玩家 / 主角）**：当年真凶。表面光鲜的成功者，把那晚压进遗忘，在谎言上重建人生。
- **林晚（受害者）**：小学美术老师，24 岁，温暖天真，暗恋"你"。被你长期跟踪，查到车主是你，7/27 想当面说清，死于你车下。生前在一个本子里抄下 5 句关于忧愁、认罪、赦免的话，每句旁画了个问号——她想找到这些话的**出处**，想弄懂"赦免"。
- **林梧（W）**：林晚的姐姐。六年追凶无果，私了复仇——找到你、致你失忆、囚禁、循环喂还记忆。代号 W 取自"梧"。无法像妹妹那样原谅你。
- **陈伯**：沿江路住户，那晚从窗口目击全程。被你花五万买通、以孙女威胁封口。晚年对林梧吐露真相。

> **关于 5 句话的性质**：游戏全程**不直接告知**玩家这些话是经文、出自圣经、或涉及任何信仰。玩家仅在阅读其内容（提到"神""耶和华"）与真实浏览器检索出处时**自行发现**。游戏层面始终以"林晚摘抄的、她想知道出处的话"呈现。

### 3.2 罪行（分层揭露）
- **表层（玩家与官方最初以为的）**：醉驾肇事逃逸，致一人死亡。你年轻有家世，连夜压下证据、买通目击者，逍遥法外。
- **深层真相（第 5 天揭）**：酒驾次要。你长期跟踪林晚；7/27 她查到车主是你、约在沿江路当面说清。你赴约是为灭口/威吓。她认出你的车，**朝你走来**——你踩下油门，撞向她。下车看了一眼，从容离开，回家转账、威胁陈伯、销毁证据。
- 官方因证据被毁从未定罪；法律给不了林梧答案，于是她私了。

> "罪行"本身也是一层谎言——玩家最初以为的"醉驾肇事"比真相轻得多，呼应"每层记忆都盖着更糟的真相"。

### 3.3 时间线
- 6/12 起：你持续跟踪林晚，社交账号留痕（"又路过她楼下"）。
- 7/15：你车贴深色膜，朋友圈晒车，车牌清晰。
- 7/19–7/25：林晚发现被跟踪，查到车主。
- 7/24：林晚 24 岁生日（Day 0 记忆）。许愿"希望他能看见我"。
- 7/27 早：林晚发消息"在吗。我有件事想跟你说。"——你没回。
- 7/27 21:40 你的车进沿江路（ETC）。21:45 你已读她消息。21:52 CCTV。22:15 事故。
- 7/28：你向陈伯转账 5 万、威胁封口。
- 此后六年：林梧追凶、找到陈伯、找到你。
- 现在：会话 #07，第七次循环。

### 3.4 反转与循环
- **反转1**（中段）：你不是旁观者，你在场。
- **反转2**（第 5 天）：你是真凶；W 是林晚姐姐林梧。
- **反转3**（终章）：这是第七次循环——你已"想起来"过六次，每次都崩溃求删，林梧再删再还。复仇 = 无尽的想起。
- **结局 A**：你沉默或求删，都通向同一结果——林梧"那就再来一次"，`会话 #07 → #08`，黑屏回到第 0 天。

## 4. 核心机制

### 4.1 W 记账（动态回声）
每个章节 W 问玩家一个自由输入问题，存入 `localStorage`。第 5 天林梧把话原样念还，逐句扭刀。

| 章 | W 的问话 | 存储键 | 空值回退 |
|---|---|---|---|
| Day 0 | 等你全都想起来，你最想做的一件事是什么？ | `q_day0` | 重新开始 |
| Day 1 | 如果当时再快一秒，你觉得你救得了她吗？ | `q_day1` | 能救 |
| Day 2 | 21:30 她发消息时，你在哪？ | `q_day2` | 在家 |
| Day 3 | 被你买通、替你撒谎的人，算不算共犯？ | `q_day3` | 算 |
| Day 4 | 她那么想你看见她。你看见她时，在做什么？ | `q_day4` | 看着她 |

### 4.2 谜题复杂度升级（五项）
1. **章内链式 3–4 段**：每章谜题由 3–4 段串联，上段解码产物 = 下段密钥/线索，最后一段合成主线密钥。少一环过不去。
2. **跨章元谜题「七夜」**：6 天 + 终章各藏一块"夜之碎片"于隐藏 ARG 层。集齐 7 块 → 解锁终章可选档案「林梧六年手记」。不卡主线。
3. **谎言机制**：红鲱鱼（当年你/买通者散布的假线索，须识破丢弃）；W 偶尔给错误提示（须交叉验证）；输入"舒适错误答案"会触发短暂"假记忆"支线，后续被证据推翻。
4. **工具箱渐进**：玩家逐步解锁工具，后续谜题须组合工具——
   `Base64解码器`(Day0) → `详情查看器`(Day0) → `频谱查看器`(Day1) → `隐写放大器`(Day2) → `坐标地图`(Day3) → `密码盘`(维吉尼亚/凯撒, Day4) → `摘抄`(收藏夹, Day1 起)。
5. **新谜题类型**：音频频谱隐写 / 图片 LSB 真隐写 / 维吉尼亚+凯撒 / GPS 坐标地图定位 / 书目密码 / 摩斯·键盘移位 / 撕碎笔记拼图 / **引文检索（真实浏览器）** / **林晚的问号（选图配出处）**。

> **难度兜底**：连续错 N 次，W 以剧情口吻给递进提示，硬但不卡死。

### 4.3 仿真桌面 · 删不掉的证据（Day 4 核心交互）
- 文件 `证据_你的车.zip` 出现在仿真桌面。
- 玩家可右键删除 / 拖入回收站 / 清空回收站；每次"删"后文件回原处，弹窗嘲讽（"你上次也清空过。管用吗？"）。
- 解开加密（密钥由社交账号线索合成）后，文件解锁、内容呈现，状态转"可删除"。
- 玩家删除后，W 念台词，文件以**永久置顶消息**形式回归——"删得掉文件，删不掉你做过的事"。

### 4.4 摘抄（收藏夹）
- 林晚生前在一个本子里抄下的 5 句话，**分散在 Day 1–Day 5 各处**（见 5.x），每句以**纯文本**出现，**不显示出处**，也**不标注其性质**（游戏不说它们是经文/圣经/信仰相关）。
- 玩家发现一句，自动收入收藏夹「摘抄」（仅显示句子文本）。
- 林晚在每句旁画了问号——她想找这些话的**出处**却没找到。这构成玩家"替她找出处"的动机。
- 收藏夹中每句提供「复制」按钮 + 可点的搜索快捷链接（打开默认搜索引擎搜该句），方便玩家随时去真实浏览器查出处。

### 4.5 引文检索（真实浏览器）
- **机制**：玩家在真实浏览器里搜索某句话的文本 → 搜索引擎置顶返回其出处（如搜"神所要的祭就是忧伤的灵" → 诗篇 51:17）→ 玩家得到**章节:节**这组数字。
- **设定接合**：终端"外部网络已断开"，W 说"我这边查不到外面。你替我查。"——断网成了 W 必须借用玩家真实浏览器的理由。
- **可靠性**：5 句话出处均为全网海量收录的和合本经文（实现参考，**不对玩家明示**），搜索置顶必中；出处（章节:节）是确定数字，无歧义。
- **离线兜底**：连续错 N 次，W 递进提示直至给出来处，保证不断流。
- **用途**：5 句话的 5 组数字 → Day 5 末「林晚的问号」选图谜题的配对依据（见 4.6）。

### 4.6 林晚的问号（Day 5 末 · 通往终章的闸门）
- 林梧把**林晚的摘抄本**推到你面前（不称其为圣经/经文），铺开 **12 张图**，每张文件名含一对数字（如 `DCIM_51-17.jpg`）。
- 其中 **5 张正确图**的数字对，对应玩家通过 4.5 查到的 5 句话出处：`51-17 / 7-10 / 1-9 / 55-7 / 3-19`；其余 7 张是数字相近的诱饵。
- 玩家把图拖到对应卡位（**按文件名数字对 = 句子出处匹配**）。5 张全对 → 每个卡位翻出一个字。

| 卡位顺序 | 句子（出处，玩家自查） | 匹配图数字对 | 翻出的字 |
|---|---|---|---|
| 1 | 诗篇 51:17 | `51-17` | 我 |
| 2 | 哥林多后书 7:10 | `7-10` | 原 |
| 3 | 约翰一书 1:9 | `1-9` | 谅 |
| 4 | 以赛亚书 55:7 | `55-7` | 你 |
| 5 | 使徒行传 3:19 | `3-19` | 了 |

连读 → **「我原谅你了」**。这是林晚没发出去的最后一句——她到死，原谅了杀她的你。输入这句话 → 通往终章。

> 表中"出处"列为实现参考；游戏内卡位只显示句子文本 + 玩家自查填入的出处数字，不预置"诗篇/哥林多后书"等宗教书卷名。

### 4.7 隐藏 ARG 层（可选彩蛋）
每章埋一个可选隐藏线索（含「七夜」碎片），奖励细心玩家：
- Day 0：生日照 LSB/调对比隐写——半截新闻标题"……交通肇事……逃逸……身亡……"。
- Day 1：7/23 夜景暗部——车窗反光里一只握手机的手，手腕旧疤。
- Day 2：CCTV 21:52 帧暗部——驾驶座车窗里握方向盘的手，同一道疤。
- Day 3：陈伯陈述扫描件边角补写小字——"她说她叫林梧。"
- Day 4：7/27 微博下注销账号点赞，头像林晚与林梧合照。
- Day 5 / 终章：集齐七夜碎片 → 「林梧六年手记」。

### 4.8 存档与重置
单一存档槽，章节解锁后写入。`会话 #07` 计数器随剧情递变含义。终章 A 后黑屏回 Day 0，存档保留"已完成"标记；可手动重置。

## 5. 章节设计

> 各章谜题统一为"链式 3–4 段 + 工具组合 + 红鲱鱼 + 隐藏层/七夜碎片"结构。下文给出每章关键 beats、摘抄位置、主线密钥；具体密码串在实现阶段填充。

### 第 0 天 · 醒来
- **开场**：冷绿自检日志逐行打出（`[ OK ]会话 #07` / `[ !! ]外部网络：已断开` / `[ ?? ]受试者编号：▓▓▓▓`）。四个可点界面：聊天窗、收件箱、备忘录、录音机；灰掉摄像头图标显示空房间（墙上日历停 7/27，门无把手）。
- **W 登场**：不解释规则。问 `q_day0`，存话，发 `memory_00.enc`。
- **谜题**：备忘录半涂黑便签（"密钥是她笑起来那年的数字"）+ 蛋糕照"林晚 24"+ 详情栏 Base64（解码"名字。岁数。一并交还。"）→ 输入 `林晚24` 解锁。
- **记忆**：生日夜聊天（"那你永远 24 / 说定了"）+ 旁白 + 3 天后未读消息（"在吗。我有件事想跟你说。"你没回）。
- **埋点**：林晚=受害者；"永远24"；"跟你有关的愿望"(Day4)；"3天后没回的消息"(Day2)；日历 7/27；会话 #07；外部网络断开(→4.5 引文检索动机)。
- **隐藏层**：蛋糕照隐写半截肇事新闻标题。
- **W 收尾**："你那时候，还配得上她那样的笑。"

### 第 1 天 · 那个人
- **W**：引出林晚其人 + 你"在场"的样子；回声 `q_day0`。解锁工具：`频谱查看器`。
- **摘抄①**：在林晚书桌一个本子的扫描页边栏，一行铅笔字（**纯文本，无出处，不标性质**）——"神所要的祭，就是忧伤的灵；神啊，忧伤痛悔的心，你必不轻看。"旁画问号。自动入收藏夹。
- **谜题 A（主线）**：5 条朋友圈截图按时间戳正序排列（7/19–7/27）→ 分钟数拼出 `0727` → 解锁 `memory_01`。内容：她最后一周被深色轿车跟踪，7/27"今晚了结"。
- **谜题 B（支线，回收 Day 0）**：林晚加密备忘录，密钥 `林晚24`（她用自己名字+岁数当密码）→ 偷拍深色轿车残牌 `苏E·▓8▓6` + 心声"我想先告诉你"。
- **记忆**：旁白立人 + 给闺蜜语音（"明天我找他当面说清"）+ 你的"记忆"（7/27 沿江路，你说你只是路过，捡起她碎屏手机读到没发出的消息）+ W"你只是来不及" + `q_day1`。
- **红鲱鱼**：一份"目击者称肇事车为白色"笔录——你当年散布的假信息，须识破。
- **隐藏层**：7/23 夜景暗部车窗反光里的手腕旧疤手。
- **埋点**：深色轿车/跟踪者(Day4)；残牌(Day4)；手机屏裂缝(Day5)；手腕疤(Day5)。

### 第 2 天 · 那一晚
- **W**："记忆会骗人。数据不会。" 解锁工具：`隐写放大器`。
- **摘抄②**：林晚笔记本夹的便签（纯文本）——"因为依着神的意思忧愁，就生出没有后悔的懊悔来，以致得救；但世俗的忧愁是叫人死。"旁问号。入收藏夹。
- **谜题（4 段链式）**：
  1. ETC 涂黑时间（十六进制）→ `21:40`
  2. CCTV 调度日志（维吉尼亚，密钥 `2140`）→ "摄像头 #07 / 沿江路口 / 录像已调走"（埋点：录像被调走=你销毁，Day4 回收）
  3. 五件证据按时间戳排序 → 暴露矛盾：21:40 车在沿江路，21:45 手机定位却写"在家"
  4. 手机定位日志用隐写放大器看出篡改前真实定位 = 沿江路 21:45
  → 合成主线密钥 `21:40` → 解锁 `memory_02`
- **记忆**：旁白（记忆崩裂）+ 林晚草稿"我查到了那辆车的车主。是……" + `q_day2`。
- **隐藏层**：CCTV 21:52 帧驾驶座车窗里握方向盘的手，同一道疤。
- **裂缝**：Day1 手机屏 + Day2 你不在家。

### 第 3 天 · 目击者
- **W**："你的记忆，挑着回来。" 解锁工具：`坐标地图`。
- **摘抄③**：陈伯归还的一张照片背面，林晚的字（纯文本）——"我们若认自己的罪，神是信实的，是公义的，必要赦免我们的罪，洗净我们一切的不义。"旁问号。入收藏夹。
- **谜题（链式）**：转账记录（你→陈伯 ¥50,000，备注十六进制解码"看见的，就当没看见"）+ 已删聊天填空（你威胁他孙女在哪家幼儿园）+ 陈伯真实陈述加密（密钥 `50000`）。

- **裂缝**：你下车看了一眼、从容离开、买通威胁——"路人"形象站不住。

### 第 4 天 · 销毁
- **W**："互联网有记忆。我也记得。" 解锁工具：`密码盘`。
- **摘抄④**：林晚被恢复的社交草稿里夹的一句（纯文本）——"恶人当离弃自己的道路，不义的人当除掉自己的意念，归向耶和华，耶和华就必怜悯他；当归向我们的神，因为他必广行赦免。"旁问号。入收藏夹。

### 第 5 天 · 你就是那个人
- **W**：语气转冷。"最后一块，只能你自己拼。"
- **摘抄⑤**：林晚没发出的最后一封信里（纯文本）——"所以，你们当悔改归正，使你们的罪得以涂抹，这样，那安舒的日子就必从主面前来到。"旁问号。入收藏夹。（5 句集齐）
- **谜题（招供序列）**：拖拽排列那晚五事件真序——①她走向你的车 ②你踩下油门 ③你撞了她 ④你下车蹲看 ⑤你开车离开。排对解锁最终影像。
- **最终影像**：驾驶座你的脸（仪表冷光）+ 握方向盘的手腕旧疤（同一只）+ 林晚走进车灯 + 你踩油门。
- **林梧现身**：W→林梧。六年追凶、法律无果、私了复仇；`会话 #07`=第七次循环。
- **念还你的话**：逐句回声 `q_day0–q_day4`，逐句扭刀（"你说再快一秒能救她——你不是来不及，你是踩了油门"等）。
- **闭合裂缝**：墓碑"卒于 7/27，享年 24"（"永远24"回收）；"她手机碎了，你读不到任何字，那段记忆是你编给自己听的"（Day1 手机屏闭合）；手腕疤=你（Day1/2 隐藏层回收）。
- **林晚的问号 puzzle（见 4.6）**：林梧铺开 12 张图 + 林晚摘抄本。玩家用真实浏览器查 5 句话出处 → 配图 → 翻出"我原谅你了"。
- **W 收尾**："她原谅你了。我没有。"

### 终章 · A 循环硬结局
- 输入"我原谅你了" → 林梧长久沉默。
- **林梧**：她到死都原谅你。可她凭什么，替我先原谅？我妹妹的命——她凭什么替我做主？她原谅你了。**我没有。**那就，再来一次。
- `会话 #07 → 会话 #08`。黑屏。回到第 0 天开场自检日志（`[ OK ] 会话 #08`）。
- **复仇 = 无尽的想起。** 赦免存在（5 句话的内容 + 林晚的原谅），却救不了你。

## 9. 风险与开放问题

- **引文检索可靠性**：5 句话出处为全网海量收录的和合本经文（实现参考，不对玩家明示），搜索置顶必中；提供离线兜底（W 递进提示至给出处）。需在实现时逐句验证搜索置顶命中。
- **联网依赖**：引文检索需玩家真实浏览器联网；无网时走兜底，保证可通关。
- **"不点破性质"的一致性**：游戏内任何 UI、文案、收藏夹命名、林梧台词都不得出现"经文/圣经/信仰/基督教"等字眼；5 句话仅以"林晚摘抄、她想知道出处的话"呈现。性质由玩家经阅读与检索自行发现。实现时需逐处审查。
- **隐写/伪元数据可发现性**：隐藏层须"可被细心玩家发现、不被普通玩家误读为 bug"。实现时给极淡视觉提示。
- **W 记账空值回退**：已定默认文本（见 4.1），避免第 5 天回声断流。
- **罪行分层一致性**：表层"醉驾肇事逃逸"与深层"蓄意踩油门"已在 3.2 显式说明为"官方/玩家初印 vs 真相"，不矛盾。
- **出处查证（实现参考）**：5 句出处（诗篇 51:17 / 哥林多后书 7:10 / 约翰一书 1:9 / 以赛亚书 55:7 / 使徒行传 3:19）已核为和合本原文，搜索可命中；游戏全程不对玩家明示其为经文。
- **循环结局的挫败感**：A 结局刻意无力；以"可主动重置 + 隐藏层/七夜带来二周目新视角"作情绪出口。
- **音频素材**：录音机/终章需少量人声；无人声录制条件时用文字 + 底噪 + 波形动画替代，不影响剧情。
